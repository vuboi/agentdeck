### What's new

- **`/release`:** a built-in command that prepares a release of the current project: finds how it releases, picks the next version, writes the notes (what's new and fixes), bumps the version files, runs the checks, commits, tags and pushes, then follows CI and any npm or zip step the project documents. It shows the version, notes and commits and waits for a yes before anything is pushed.
- **Sync skills & MCP in parallel:** each row syncs on its own and shows its own spinner; several can run at once.
- **Confirm before removing:** removing an MCP server or a skill source asks first, in the same dialog as removing a skill.
- **Input fields take the focus** when the Add source, Import, Add MCP server and Edit flow dialogs open.
- **File tabs:** the active file tab uses the same colour as the active chat tab.
- **"Add to library"** uses a folder-plus icon.

### Fixes

- **Edit source flickered on opening:** the Save button spun while the source loaded and jumped between states. It now spins only while saving, the fields are disabled while loading, and the labels stay put when the dialog closes.
- **Small dialogs had a tall empty body** (Add skill source, Import skill or MCP config, Add MCP server, Edit flow, Claude Console): the extra space is gone, and Import is narrower with Browse under the field.
