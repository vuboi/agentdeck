### What's new

- **Free-tier providers stay away from private data:** a custom provider can be marked "Free tier" (Gemini, Groq, Cerebras and OpenRouter free presets come marked). It gets web search only: no files, code, terminal, browser or MCP tools. AgentDeck blocks, before anything is sent, any message, attached file or tool call that holds a secret, an environment variable, an internal IP or host name, or a file such as `.env`, a key or a credentials store, and it never follows a redirect into your network. Claude, Codex and Antigravity may hand such a provider light public work (search, emails, prompts, small text edits) and are told what must not go.
- **Carry on when a usage limit resets:** when a chat stops at a limit and no other agent can take over, AgentDeck reads the reset time from the error (or the account's usage) and carries on by itself. A card above the message box counts down, with a switch to turn it off, Try again and Cancel. Settings has the same switch.
- **Find in the whole app (Ctrl+F)** marks every match on screen, with next/previous, match case and a count. A file with the cursor in it keeps its own find. **Ctrl+/** lists every keyboard shortcut, with search. Ctrl+W closes the tab and Ctrl+P searches chats, as their menus always said.
- **Export and import your data** (Settings > Sync): settings, providers, flows, permissions, layout and theme go to one file and come back after a reinstall or on another computer. Chat history and API keys are optional.
- **Sounds and videos play in the viewer,** with a waveform, skip, speed and volume. Pictures, sounds and videos an agent wrote (`![x](/C:/…/a.wav)`) show as cards under its answer.
- **Usage shows costs for Codex and Gemini models,** worked out from published list prices (marked ≈), and you can type a price for any other model. More figures: replies, tokens per reply, output tokens, cost per reply.
- **Time to reset in the account menu:** each account shows a live countdown (days, hours, minutes, seconds) to its next reset.
- **Free models first:** in the model pickers (chat and image generator) free models are listed on top, with a "Paid" divider.
- **OpenRouter and other free cloud providers** can be added in one click from Settings > Providers, with their logo.
- **Loading bar** like the chat's on files, diffs and Changes, instead of a spinner in the middle.

### Fixes

- **Smoother chat scrolling and loading older messages:** older messages load only when you scroll up near the top, never in a chain, and not while the scrollbar is dragged. Code colouring now runs in its own thread (and is kept between runs), rows that are folded are built only when opened, and the list no longer forces a layout on every frame. Frames of over a second while scrolling a long chat are gone.
- **A Codex answer with `<pre>` in backticks no longer breaks the page:** inline code is shown as text.
- **Many "Thinking" boxes in one Codex reply are one box.**
- **Code colours appear faster** in files and chats (the colouring engine is the one the grammars are written for, and the part on screen is coloured first).
- **A file opens without jumping:** the viewer keeps its frame while the text loads.
- **Antigravity sign-ins survive token renewals:** switching accounts no longer refuses a saved login only because its access token expired.
- **Popover and menu fixes:** the model picker's arrow lines up, search boxes in pickers return to the top of the list, the edit box scrollbar sits flush with its border, and modal scrollbars are slim.
- **Edit cards:** the file name in a step opens the file; inside the card only the path shows, and it stays put while the diff scrolls.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
