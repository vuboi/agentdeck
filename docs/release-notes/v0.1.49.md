### What's new

- **Project memory gets suggestions.** When an agent finds a better way to work in a project, it writes a proposal to `.agentdeck/proposals.md` instead of changing the memory. Settings → Project memory lists each proposal under "Suggested by agents": **Keep** adds it to the memory, **Drop** removes it. The memory itself is not changed without your choice.

### Fixes

- **Memory note stays within the cut.** The project memory note sent at the start of a chat now tells the agent where to put proposals; the 3000-character cut for the memory text is unchanged.
