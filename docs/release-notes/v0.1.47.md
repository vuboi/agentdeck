### What's new

- **Choice cards work with every agent.** OpenCode and Antigravity now receive the same instruction as Claude and Codex to open AgentDeck's multiple-choice card when a missing decision would otherwise waste work.
- **Context compaction waits for a genuinely large chat.** Claude compacts at 200k tokens, or 75% of a smaller model window. Fork handoffs keep the full conversation below that threshold and compress only large histories.
- **Fork from a message.** A fork started from an earlier message contains the conversation through that point, without copying later turns or a run that is still active.
- **Claude Console keys use the provider form.** Adding and editing Claude Console credit now follows the same provider flow as other API keys, including validation, account switching and credit refresh.

### Fixes and polish

- **Queued messages keep their order** while the current turn or a user decision is active, and completion notifications wait for delegated work to finish.
- **Preview addresses copied from coloured terminal output** open correctly, navigation failures appear in the page area, and development attachment folders are allowed by the asset protocol.
- **Agent activity is easier to scan:** repeated titles are removed, content text is larger, running commands truncate cleanly, and activity icons keep a stable alignment.
- **Question cards use the shorter “Send” action.**
