### What's new

- **Dev and installed builds are separate.** A build run from source keeps its own data folder (`~/.agentdeck-dev`) and registers its browser server for agents under its own name (`agentdeck-dev`). It no longer reads, writes or re-points the installed app's history, indexes, attachments or Antigravity browser link.

### Fixes

- **Preview reloads:** when an agent opened AgentDeck inside its own Preview, the page reloaded again and again, nested windows, and replayed each chat's events, which froze the app. Chat events and agent open requests now reach only the main window, and the Preview's copy of the app starts nothing of its own.
- **Freezes while streaming:** a reply streamed into a chat is applied once, not again by every Preview copy of the app open at the same time.
