### What's new

- **Larger plans are delegated.** Implementing a larger plan (several files or steps) now goes to delegate_task workers: the plan is split into independent work packages on disjoint files, one worker each, and the main agent keeps the integration. Small or single-file edits, quick commands and simple artifact actions stay in the current chat. The guidance is updated in the tool description and in the start-of-chat hint.

### Fixes

- **Foreground commands stay in the chat.** A plain Bash command that the CLI also reports as a task is no longer moved into Agent & background activity. It keeps its ordinary command row. Only background calls (run_in_background shells, sub agents) take a task row, both in the chat and in the Work tray.
