### What's new

- **Markdown attachments preview as rendered Markdown:** opening a pasted or attached `.md` file shows headings, tables, quotes and links instead of plain text (z-ui 0.1.17).
- **Remove several Codex accounts at once:** each account's trash button spins on its own and the others stay usable.
- **Tasks log fills itself:** changing the range or project reads older logs until the list is full; the "Load 50 older logs" button is gone. Loading and empty states sit in the middle of the pane.
- **Error log and background-process drawers:** a custom header (icon, title, close) with the scrollbar starting below it; empty states centred.
- **Extensions menu:** the footer is an outline "Add unpacked extension…" button.

### Fixes

- **The sign-in dialog could not be closed while waiting for a login:** Cancel, the close button, Esc and a click outside did nothing. They now close the dialog and cancel the pending sign-in.
- **Removing a Codex account blocked removing the others:** all remove buttons were disabled while one ran, and the clicked button showed no progress. Each row now has its own spinner.
- **An extension's name showed a tooltip even when it fit:** the tooltip now appears only when the name is cut short.
