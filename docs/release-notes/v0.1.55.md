### What's new

- **Tooltips on truncated menu items.** Context menus and pickers show a tooltip to the right when an item's label is cut short, such as "Copy message as Markdown".
- **Clearer status before the first event.** Ordinary messages to the main agent show **Thinking** straight away instead of "Sending task to …". Tasks handed over to a worker chat show both the agent and the model label, for example `Sending task to Codex · GPT 5.6`.

### Fixes

- **Closing the window hides it to the tray.** Pressing X hides the main window to the system tray instead of leaving it minimized on the taskbar. Left-clicking the tray icon or launching the app again restores the window.
- **Work tray Stop no longer interrupts the main chat.** Provider-native background tasks (such as background commands) no longer show a row-level Stop button that would stop the entire chat turn. Row-level Stop only ends delegated workers and child chats.
- **No leftover background report after Stop.** Background tasks marked stopped when you press Stop are excluded from auto-turn report candidates, and stray CLI reports arriving right after Stop are ignored instead of opening a new "Task result · Background work report" reply.
