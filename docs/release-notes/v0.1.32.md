### What's new

- **Flows judged by their runs:** Workflow → History scores every flow over the runs kept: the share of runs that were right (every step finished and none was blocked), the share of steps right, the tries per step (1.0× means nothing was redone), the time and cost of a run, and what a right run costs once the wrong ones are paid for. Pick a flow in the table for a sentence that sums it up and two lines, cost and time per run over time, a dot per run (green right, red wrong).
- **Guard for commands that cannot be undone:** a shell command that would erase the root, the home folder or a whole drive, format a disk, write straight to a disk device or fork-bomb the machine is refused in every permission mode, even after an earlier "always allow", and the agent is told why. It covers the custom chat (local models) and Copilot; the other agents decide for themselves in their own CLIs. Anything else that only looks risky is still left to the mode.
- **Long tool output keeps both ends:** the custom chat gave the model only the end of an output longer than 12,000 characters. It now keeps the start and the end around a marker that says how much was cut. A command keeps mostly its end (where the verdict is), a page or a file mostly its start.
- **Leftover files:** `pnpm clean:junk` lists the files a work session leaves by accident (a Word or Excel file made to try something, a log, a screenshot of a check) and `pnpm clean:junk:delete` removes them; only files git does not know are touched. A pre-commit hook (`pnpm hooks:install`) refuses to commit them.
- **Dev build:** the Workflow tab has a "Load demo runs" button that fills the history with made-up runs to look at the scores. It is not in the installed app and the runs are never saved.

### Fixes

- **A flow's success was only "every step finished":** a step whose handoff said it was blocked or needed the plan changed counted as a success. It now counts as wrong.
- **Long output of a custom chat lost its beginning:** the first lines of a long file read or page were cut (see "Long tool output keeps both ends").
