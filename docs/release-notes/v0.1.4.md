### What's new

- **Preview opens the address the server prints:** the address is taken as printed in the run log (http or https, host, port and path). A server that only answers over https no longer ends on a browser error page, and self-signed certificates on localhost are accepted. A page that fails to load keeps the address you typed and shows a short error with Reload instead of `chrome-error://`.
- **Run project, clearer failures:** package.json scripts that run a `node` wrapper are marked, a failed start shows a cleaned log tail with a hint (missing dependencies, port in use), and a script that waits for a keyboard is stopped early with a button to run it in the Terminal.
- **Background processes drawer:** a floating drawer with one card per process (project, command, state, running time to the second, Stop and Stop all). Several processes can start at once, a process that never answers is stopped after 5 minutes, and commands running in the Terminal are listed too.
- **Live command output in the Audit log:** Run project, Terminal and Bash entries open as a command card with a live, scrolling, coloured output box, Copy and Stop.
- **Ctrl+L** focuses the address bar even when the page has the keyboard.
- **Fixes:** code blocks in chat no longer show empty after scrolling, the terminal scrollbar matches the app's, the flow step settings drawer floats, and the duplicate key error in the processes list is gone.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
