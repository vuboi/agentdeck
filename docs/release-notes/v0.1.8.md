### What's new

- **Handing work to other agents costs fewer tokens:** an agent you ask with `@claude`, `@codex` and so on still answers you in full in its own chat, and also ends with a compact "Handoff" digest (up to 600 words, shared between the agents asked together). Only the digest goes back to the main agent, which writes the reply from it. Each full answer stays one click away in the agent's chat.

### Fixes

- **The main agent no longer does the work again after an agent answered:** when nothing failed, it is told not to run commands, read files or inspect git, and only to combine the digests into a short reply. It re-checks and fixes only when an answer reports `VERDICT: FAIL` or `STATUS: blocked`.
- **Very long answers** put into the hand-back prompt are cut (the rest stays in the agent's chat).

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
