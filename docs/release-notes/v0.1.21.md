### What's new

- **Team runs:** a flow can now be a team. The first step plans (a BA); the others (frontend, backend, QA, DevOps, or any role you name) work at the same time, each in its own chat, and send each other messages through a queue until all are done. The queue, each member's state and a log are saved, so a restart or a failed turn carries on where it stopped. Two presets are built in ("Product team" and "Full team" with QA and DevOps); turn on Team mode in the flow editor for your own. The canvas draws a line between neighbouring members.
- **Three switches in the model popover:** auto-compress context (Claude: compact a long chat before it runs out of room, shown as "Compressing context"), auto fallback (now off until you switch it on) and auto-orchestrate (let the agent hand light or separate parts to other agents).
- **Error log:** problems met while working (a failed turn, a step or team member that stopped, a hand-back that never ran, an agent quiet for 5 minutes, errors in the page) are kept in a file. A button in Tasks opens them in a drawer, with a button to save the file for debugging.
- **Providers in one place:** Claude Console API credit and the free cloud providers sit together, each editable in a window over the settings. Cloudflare Workers AI is added. Free ones carry a "Free" tag.
- **Pick a model with its logo:** the model list in a step is a tree: choose an agent or provider, then its model, with search across all of them.
- **Saved API keys stay hidden:** once saved, a key shows only its ends and can only be replaced.
- **Claude API credit** shows the credit left under the message box when the Console sign-in is added.

### Fixes

- **Streaming answers no longer jump:** the reply being written keeps its measured height, so the text stops moving up and down while it streams.
- **Changing a message while the agent works no longer hangs:** stopping ends the whole process of the agent on every system, so the next turn does not wait on the old one.
- **System notifications on Windows carry the AgentDeck logo,** without the check mark; Send a test sits under its text.
- **The update window** is wider, its scrollbar matches the chat's, and it scrolls to the top when the download starts.
- **Keyboard shortcuts** use the same scrollbar as the chat.
- **Lists in pickers fade at both ends** while scrolled, and show group dividers.
- **Testing a Claude API key** no longer fails with a 404.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
