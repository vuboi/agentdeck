### What's new

- **Update dialog shows the changelog as formatted text:** headings, lists, bold and code, in a slim scroll area, instead of raw Markdown.
- **Developer aid:** `pnpm dev:update` starts the app with a pretend update waiting, to see and style the update dialog without publishing a release.

### Fixes

- **The changelog in the update dialog showed raw Markdown** (`###`, `**`, backticks); it is now rendered.
- **The dialog's scrollbar sat inside a padding**; it now uses the slim overlay scrollbar on the dialog's edge.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
