### What's new

- **Messages sent while the agent works** wait in line (Enter) and go out as one message when the reply is done: one turn, one model, one answer. Ctrl+Enter stops the running reply and sends at once. The "run beside" mode and Alt+Enter are gone.
- **Computer use runs on its own:** with "Allow agents to use this Windows computer" on, screenshots, clicks and typing run without an approval card. The mouse goes back to where it was after a click.
- **Sign-in in Settings:** while a login waits, the button reads "Waiting for login…" (disabled) with Cancel next to it, for every connector.
- **Switch account** dialog can be cancelled while it works (z-ui 0.1.19).
- **File viewer:** dragging the side panel (files or changes) follows the pointer exactly.

### Fixes

- **Quota bar turned grey after switching accounts:** at 30% or less the fill and its dot used a colour the app does not define. They are now amber (red at 10% or less).
- **Chat lag while saving:** every save copied all local chats on the main thread; saves close together are now merged into one.
- **File viewer panel resize felt like a wave:** the width transition ran while dragging; it now applies only when opening or closing.
