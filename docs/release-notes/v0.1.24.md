### What's new

- **Store:** a marketplace for plugins, MCP servers and skills, in the Tools panel. The Installed tab manages what is on the machine (agents on or off per skill, plugin enable, uninstall). Discover lists plugins from the Claude and Codex marketplaces, MCP servers from the official registry, and skills from repositories you add in Sources.
- **Add from outside:** install a skill, MCP config or plugin from a git address, a zip, a single URL or a folder. Nothing runs before it is scanned, and an agent (Claude or Codex) reviews it read-only. A block stops the install; a caution asks you to read the warnings first.
- **Updates:** skills that came from a git source are checked against it, and an update is scanned again before it replaces the library copy.
- **Use a plugin with both agents:** a plugin's skills and MCP servers can be shared with Claude and Codex.
- **Log in to an MCP server over OAuth** from the Store (Codex).
- **Diff view:** select text in a change, right-click to copy the selection or all changes, or add them to the message box.
- **Copy a message with its attachments:** Copy on a message with pictures, notes or files copies them too, so pasting into the message box brings them back.

### Fixes

- **Switching accounts no longer stalls the next reply:** after a switch, Claude, Codex and Antigravity start a new session that carries the conversation so far, instead of resuming the old one.
- **Messages sent while Codex is replying wait in line** and go out together once its reply is done, instead of landing in the middle of it. Claude still answers beside its running turn.
- **Codex file changes count only the lines that changed**, not the whole file (the +/- numbers in the command group).
- **Browser inspect and mark-up** end cleanly when the page is recreated (switching Desktop, Tablet or Mobile), reloads, or the tab changes, so they can be turned on again.
- **Chat column** keeps a minimum width when the side panels are resized.
- **Development builds** run on their own port and identifier (`AgentDeck Dev`), so they run beside the installed app.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
