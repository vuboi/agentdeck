### What's new

- **Estimated cost per month** in Usage: the average cost per day since the first reply, times 30 (for the chosen project).
- **Tables read better:** each column sizes to its content up to a reading width and then wraps, so one long column no longer squeezes the others into a sliver. A wide table scrolls sideways.
- **Steadier text at the end of a reply:** once the agent is done, the rest of the answer is shown within about 3 s, still word by word. When you send a new message, the previous answer is shown in full at once, so two replies never look like they run side by side.

### Fixes

- **No more answers repeated after the app was killed:** the agent CLIs (Claude, Codex, Antigravity, OpenCode) now end with the app, even when it is killed, instead of running on in the background and writing into the conversation.
- **Editing a message starts a new conversation** for the agent, given the chat before the edited message. It used to resume the old one, which still held the removed turns, so the agent could answer them again.
- **Usage** no longer shows the Replies card.
