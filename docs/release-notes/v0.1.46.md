### What's new

- **Provider keys go to the system credential store.** API keys of custom providers and the Claude Console key are kept in Windows Credential Manager, the macOS Keychain or the Linux Secret Service, not in the app's database. Keys saved by earlier versions move there when the app starts. Without a store, the key stays in the database as before.
- **Claude Console keys are providers of their own.** Each key added from the Claude Console card becomes a row under Custom providers, with its own switch and auto switch. The card shows a check once a key is added; the button still adds another key.
- **GitHub Copilot CLI is installed from Settings.** It is pooled per chat and started before the first message, like the other CLIs.
- **OpenCode runs through its local server.** One `opencode serve` is shared by the app, one session per chat, with streamed text, tool calls and usage.
- **Antigravity usage per account.** One Usage card lists every saved account with its own limits, read with that account's own sign-in.
- **Live reset countdowns.** Reset times on every connector count down each second under two days.

### Fixes

- **Chat scroll position:** a chat whose reply is still streaming keeps the place you scrolled to when you switch away and come back.
- **Deleting a provider** asks in the app's standard confirm dialog, and the second delete works again.
- **Installing a CLI** no longer flashes back to Install before the card shows the new state; the buttons and the account area animate into place.
- **Connector headers** have one height, so GitHub Copilot, Claude and Codex line up.
- **Export and import** carry the automatic switching and the saved account list; keys are included only when you ask for them.
