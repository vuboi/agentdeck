### What's new

- **Files open in an editor:** the file viewer is now editable (CodeMirror), with Ctrl+S to save, a dot on the tab while there are unsaved edits, a Save item in the tab's right-click menu, and a warning (no modal) when closing or when the file changed on disk.
- **Git changes in the gutter, as in VS Code:** green for added lines, blue for changed lines, red where lines were removed, with matching ticks along the scrollbar. Click a tick to jump there.
- **File toolbar:** Wrap, Search (all matches highlighted; case, whole word, regex), Format, Copy, and Preview for Markdown. It turns into icons with tooltips when narrow; path, language, lines and size moved to a footer.
- **Syntax colours everywhere:** html, scss, Dockerfile, yaml, toml, php, sql and more, in the file viewer and in chat code blocks. Long code blocks scroll sideways and have a Copy button at the bottom.
- **Explorer:** search files by name, New file / New folder / Rename inline in the tree, Delete with Undo, right click marks the row.
- **Attachments:** attach any file (picker or drag and drop), with chips and previews: PDF, Word, Excel, PowerPoint, text and code open in the same viewer as pictures. "Copy all" copies a message with its attachments, and pasting restores them. Pictures an agent took show in the chat.
- **Browser:** favicons, at most 8 tabs with an overflow menu, a lock icon with details, and address suggestions from history and Google.
- **Flows:** steps expand in the chat, the approval card names the real agent, a notice tells you when a step waits for approval, and the run graph can turn horizontal or vertical. A finished flow no longer opens a browser on its own.
- **Chat:** right click on text: Copy, Copy message, Copy as Markdown. Sending a message scrolls to the end.
- **Smaller things:** fast mode starts on, narrower model popover, tab tooltips that wrap, matching toolbar heights, and a sidebar footer border.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
