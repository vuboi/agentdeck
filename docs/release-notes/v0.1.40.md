### What's new

- **Tasks log counts from the start.** Day headers show the full number of calls and failed calls for that day, read from a per-day index kept beside the log.

### Fixes

- **Sidebar tree:** folding a heading and Show more / Show less no longer lag. The tree is built in linear time, and the extra row animation that drew each change twice is gone.
- **Tasks log:** folding a day no longer loads older entries, and the pane no longer goes blank when a fold shortens the list.
- **Sign-in dialog:** Cancel, Escape and the backdrop close the dialog while it waits for the login. Needs `@shival99/z-ui-svelte` 0.1.19.
- **Settings:** the Antigravity button to add a second account is now "Add account".
