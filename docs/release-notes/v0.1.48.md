### What's new

- **Error details show readable JSON.** Error log entries, audit rows and chat error steps that contain JSON, including JSON nested inside a message or as an escaped string, are printed as indented JSON. The text around it is kept.

### Fixes

- **Cloudflare Workers AI accepts chats again.** Text-only models receive plain string message content, so the `Type mismatch of '/messages/0/content'` 400 no longer appears, and tool-call assistant messages keep string content too.
- **Cloudflare test no longer fails with 405.** The provider test uses the preset model instead of calling the model list endpoint, which Workers AI does not allow.
- **The last streamed line is no longer dropped.** A line that arrives without its trailing newline at the end of a stream is now counted as a delta.
- **Error log detail scrollbar is narrower,** matching the chat content scrollbar.
