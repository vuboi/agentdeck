### What's new

- **Running commands survive a reload:** a command running in the Terminal or started with Run project keeps its entry in Tasks (with its original start time and live output) and its row in the background processes drawer after F5. The terminal takes over its shell again and replays the last output. An entry whose process is gone is logged as stopped instead of disappearing.
- **Every run gets its own entry:** running the same command again, in the same tab, creates a new entry with its own time and output.
- **Run in the project folder:** the Run button on a chat code block now changes to the chat's project folder first, instead of running wherever the shell happens to be.
- **Command cards:** the title and time are no longer repeated inside the card, a running entry shows its time once, and the stop and copy buttons have the same size.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
