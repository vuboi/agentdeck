### What's new

- **Command cards are tidier:** the title and time are no longer repeated inside the card, a running entry shows its time once, and the stop and copy buttons have the same size.
- **Run in the project folder:** the Run button on a chat code block changes to the chat's project folder first, instead of running wherever the shell happens to be.

### Fixes

- **Running commands no longer vanish on reload (F5):** a command running in the Terminal or started with Run project keeps its entry in Tasks (original start time, live output) and its row in the background processes drawer. The terminal takes over its shell again and replays the last output; an entry whose process is gone is logged as stopped instead of disappearing.
- **Running the same command again is tracked:** every run now gets its own entry with its own time and output. Before, only the first run of a command showed up in Tasks.
- **Terminal opened in the wrong folder:** commands from a chat code block ran in the home folder (`nx` not found); they now start in the project's folder.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
