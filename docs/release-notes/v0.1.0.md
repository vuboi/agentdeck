First public release of AgentDeck.

### Highlights

- **Many agents, one chat:** Claude Code, Codex and Antigravity, with switching mid-chat.
- **Steps you can follow:** commands fold into one live line, the agent's plan shows as a checklist card, file edits show coloured diffs.
- **Run in terminal:** shell code blocks have a Run button.
- **Preview browser:** the agent can operate your page; developer tools are docked below it.
- **Multi-agent flows:** canvas editor, templates, review and fix loop, per-flow history.
- **Sidebar:** Pinned, Recents and Projects, with trust prompt for new folders.
- **Updates inside the app:** a download button next to Settings checks for a new version and installs it.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
