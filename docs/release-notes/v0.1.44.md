### What's new

- **Automatic account switching for every connector.** Codex, Claude, GitHub Copilot and Antigravity can switch to another saved account when quota or sign-in fails. Each connector card has its own switch; OpenCode shows it disabled.
- **Antigravity usage per account.** One Usage card lists every saved account with its own limits, read with that account's own sign-in. Accounts whose sign-in ran out show a sign-in button instead of a message.
- **GitHub Copilot runs its own CLI.** The Copilot CLI is installed from Settings → Connectors, like Claude and Codex, instead of being bundled in the app. The app is smaller, and the CLI is pooled per chat and started before the first message.
- **OpenCode through its server.** OpenCode runs as one local `opencode serve` shared by the app, one session per chat, with streamed text, tool calls and usage.
- **Provider form redesign.** The add and edit provider window has one field per line, a boxed API keys section with an Active key marker, and a clearer Auto switch row.
- **Live reset countdowns.** Reset times on every connector count down each second under two days.
- **Export includes account switching.** Settings export and import now carry each connector's automatic switching and its saved account list (emails and usage, no tokens).

### Fixes

- **Connector headers** have one height, so Copilot, Claude and Codex line up.
- **Version checks** show a grey "Checking…" while reading and then turn green with the version, in the connector cards and in Office.
- **Account menu** shows Auto switch as a fixed footer under the account list, and the list shows at most five accounts before it scrolls.
