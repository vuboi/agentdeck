### What's new

- **Office files for agents:** Settings → Office files installs [OfficeCLI](https://github.com/iOfficeAI/OfficeCLI) on demand (downloaded once from its GitHub release), registers it as an MCP server for Claude, Codex, Antigravity and Copilot, and installs its skill, so agents can create, read and edit Word, Excel and PowerPoint files with no Office installed.
- **Agents end with the app:** agent CLIs, terminals, MCP servers and custom-chat shells now end when the app ends, even when it is killed (End task) or crashes: a job object on Windows, a watchdog on macOS and Linux. A list of the processes the app started, with their start times, lets the next start end anything an earlier run left behind. One kill function is used everywhere; `docs/platform-support.md` lists what differs by system.
- **Delegated workers:** up to 4 run at once (was 3). A worker that failed has a retry button, and a row shows how many messages wait in that worker's chat.
- **Icons on the steps:** each kind of step (edit, create, delete, run, read, search, fetch, agent, page, plan, MCP tool, skill) has a small icon in the activity list.
- **Connectors as tabs:** Claude, Codex, Antigravity, OpenCode and Copilot are tabs along the top (with brand icons and the number of accounts) instead of one long list. Settings is a little wider for them, and the page keeps its scrollbar space so nothing jumps while it loads.
- **Providers:** Claude Console is the first card of the cloud providers, with a "Credit" tag.
- **Office files page:** the install button is an outline button with an icon, and the installed version shows as a tag.
- **Run state reducer:** a chat's run (idle, starting, running, error, and waiting for an approval) is tracked by one pure reducer, wired into turn start, agent events, Stop and permission answers. It is recorded now; deciding what to send or queue from it comes next.
- **z-ui 0.1.13:** the `bar` tabs strip keeps the same inset at the sides as above and below.

### Fixes

- **Web pictures:** a public address that redirected into the local network was followed. Every redirect is now checked, the picture is read with a 15 MB cap while it downloads, and the picture cache is pruned (200 MB on disk, by size in memory).
- **Process list:** the list of started processes no longer grows with every turn, and a damaged file is moved aside instead of blocking start-up.
- **Sign-in:** OpenCode and GitHub (`gh auth login --web`) run without a terminal and never opened the browser; the first address they print is opened for you, with a button to copy GitHub's one-time code. A long sign-in line wraps instead of widening the page.
- **"Sign-in is already running":** signing in again ends the earlier sign-in that was still waiting, instead of refusing until it timed out.
- **Tests:** the worker-limit tests were written for exactly 3 workers; they now follow the limit.
