### What's new

- **OpenCode as an agent:** OpenCode sits beside Claude, Codex and Antigravity. You can install it and sign in (ChatGPT in the browser) from Settings, chat with it, and hand tasks to it. On Windows it is found even when Node was installed with mise.
- **Install Antigravity from Settings:** the Install button now runs Antigravity's own installer, so you no longer have to fetch it from the website.
- **Reference pictures in the image generator:** paste or drop up to 5 pictures into the prompt box. They go to the generator and to the prompt suggestions.
- **Image settings under the prompt:** a row of chips picks Style, Domain, Audience, Ratio and Resolution. Each one has an icon, a search box, and arrow-key and Enter support. Auto sends nothing. Suggestions now give 5 prompts plus keywords, and clicking a keyword sets the matching option or adds the word to the prompt.
- **Picked page elements carry a picture:** an element picked in the browser is sent to the agent as a screenshot of just that element, along with its markup.
- **Folded sidebar opens on hover:** hovering the sidebar button shows the recent chats drawer. A click brings the full sidebar back, even while the drawer is open.

### Fixes

- **The active tab stays in view:** in the chat and browser tab strips, the chosen tab scrolls into view, including when you pick it from the arrow menu. A fade on the left shows when tabs are hidden on that side.
- **Changes view shows a spinner** while git is read. It used to be an empty pane.
- **Task filters wrap onto new lines** instead of scrolling sideways, and the active device or rotate row in the browser menu is highlighted.
- **The image timer shows whole seconds** ("43 s", "1m 05s").
- **The image script ships with the app,** so an installed build can generate images without a separate skill folder.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
