### What's new

- **Faster replies from Codex:** Codex now stays open between the messages of a chat (through `codex app-server`), so a follow-up no longer waits for it to load its settings and MCP servers: about 2 s instead of 6 s. Its answer and reasoning appear as they are written. Changing the model or the effort keeps the conversation, and auto-approve mode keeps the process too.
- **Claude and Antigravity stay open too:** the CLI is kept between the turns of a chat, so a follow-up is about 1.5 to 3 s. It is started while you type your first message, and ends after 10 idle minutes (at most 4 kept at a time). Stopping a turn, an error, or switching the account ends it.
- **Store, a bar on every tab:** the same search box, refresh and add buttons on Installed, Discover, Updates and Sources. The search waits until you stop typing. On a narrow panel the buttons fold into a menu, and the Skills, Plugins and MCP switch shows icons with their counts.
- **A faster Discover:** the catalog loads a page at a time, and the list keeps its place while it loads (placeholder rows are the size of the real ones).
- **Install OpenCode from Settings** works with npm 11 (its install script is allowed), so the `opencode` command exists after Install.
- **Reply status:** the "Looked at N things" line shimmers while the reply is still being made, like a running command. A stopped reply says "You stopped after …".
- **Inspect keeps picking:** after an element is added to the message, Inspect stays on, so several can be added one after another.

### Fixes

- **Queued messages go one at a time:** after you stop a reply, the next queued message goes out and the rest stay in line. Codex used to send all of them together as one message.
- **OpenCode messages wait in line** while it replies (Enter), instead of being answered beside it; Ctrl+Enter still stops it and goes first.
- **A new session after an account switch** only carries the conversation so far when the message needs it ("do it", "continue"); a message that says what it is about goes as it is.
- **The right panel keeps the chat usable:** it can no longer be dragged so wide that it covers the message box (the chat column keeps 400 px).
- **Store lists** have no padding beside the scrollbar, and the plugin actions are separate buttons: switch, divider, share, uninstall.
- **The update dialog** keeps its reading place when the download starts.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
