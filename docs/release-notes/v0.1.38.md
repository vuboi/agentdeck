### What's new

- **Chat continues during background tasks:** when a tool runs in the background (Agent tool, `run_in_background`), the turn stays open. The chat no longer closes at the first result and reopens when the task finishes; it flows as one continuous message with a "Background task completed" indicator inline.
- **Abstract chat layer:** each provider (Claude, Codex, OpenCode, Antigravity, Copilot) declares its capabilities (mid-turn message injection, parallel messages, auto-generated turns). The UI can now consume capabilities instead of hardcoding provider logic.
- **Message classification:** the app now classifies incoming messages as "related" (inject into the running turn) or "independent" (start a new turn), based on provider capabilities and turn state. This prevents unrelated messages from creating orphan turns when the chat has concurrent workers.

### Fixes

- **Chat hanging on background tasks:** background jobs and sub-agents no longer cause the turn to close early. The turn waits for all background tasks to complete before marking done, and auto-generated turns render correctly.
- **Multi-turn event chaos:** added turn state tracking and message classification to prevent events from one turn bleeding into another when multiple turns are generated (e.g., e2a/e2b scenarios: messages sent during or after text streaming).
