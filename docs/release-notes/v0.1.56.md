### What's new

- **Work can be stopped independently.** The Work tray now has one global **Stop all** action and a row-level Stop action where the row owns its cancellation handle. Stopping a project server, delegated worker or child chat targets only that work item; it does not stop the main chat turn.
- **Reliable background project state.** AgentDeck keeps project-run Work rows synchronized with the server registry, including when a process is stopped outside the app. The Preview reuses a compatible existing tab before opening another one.
- **Local history keeps AgentDeck work details.** Automatic background reports and work cards are archived locally so older sessions can restore the same content after an update or reload.
- **Session and project cleanup.** Sidebar actions can remove all projects from the list or delete every chat in a project, with the existing recoverable trash flow.
- **Clearer running and completed chat status.** Sidebar rows show an active pulse and briefly highlight work that completed while another chat was open.

### Fixes

- **Old history no longer loses work-result HTML and content.** Provider history parsers cannot represent every AgentDeck-only work block, so the local archive is merged back when a session is opened or exported.
- **Deleting an idle history session no longer fails because of a recent file timestamp.** Deletion now relies on the filesystem move to detect a real writer, and releases only that session's warm CLI before deleting it.
- **Copying chat images works for Tauri asset URLs.** Images are read through the native file bridge when the WebView cannot fetch the asset URL directly.
- **Composer focus survives external terminal and window notifications.** Focus is restored only when the composer had focus before the window lost focus, so explicit terminal interaction remains unaffected.
- **Work tray and composer queue share one aligned tray.** Background work and queued messages no longer create mismatched nested panels around the composer.
