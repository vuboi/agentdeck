### What's new

- **Tasks log counts from the start.** The day headers (Today, Yesterday, …) show the full number of calls and the failed ones for that day, read from a per-day index kept beside the log, so they do not wait for the pages to load. Older entries still load as you scroll.
- **Antigravity accounts:** the button to add a second account is now "Add account", the same as for the other providers.

### Fixes

- **Tasks log:** folding a day no longer starts loading older entries, and the pane no longer goes blank when a fold shortens the list.
- **Sign-in dialog:** Cancel, Escape and the backdrop close the sign-in dialog while it waits for the login (the dialog used to spin with no way out). Needs `@shival99/z-ui-svelte` 0.1.19.
- **Settings:** a warning about a derived value read after the settings dialog closed is gone.
