### What's new

- **Chats keep working while a worker runs.** A `delegate_task` call that waits for its report no longer locks the chat: a new message goes to the chat's listener lane, with a note that the previous task continues in the background.
- **Continue a worker with another agent or model.** `delegate_task` with `continue=<task_id>` can now name a different agent or model. A worker that finished or failed is replaced by a new worker that receives the previous worker's transcript (labelled with its old model) or its final report.
- **Worker watchdog.** A worker that runs long gets progress check-ins at 10, 20 and 40 minutes. A worker that goes silent is stopped only when no child process of it is still using CPU or I/O.
- **Worker language follows the request.** Sub agents answer in the language of the original request. When the provider's quota is past half, they switch to short English. An explicit language demand in the prompt always wins.
- **Click a file name in command rows.** Read, Edit, Write and Created rows underline the file name on hover and open it in the file viewer without expanding the row.
- **Agent & background activity** is the new title of the card that lists native sub agents and background commands.

### Fixes

- **Tasks cards line up.** Status and elapsed time sit in fixed columns in both the Tasks cards and the Agent & background activity card, and use the same time format.
- **Finished Bash calls leave the Work tray.** A command whose task event arrived before its tool result is no longer put back to running.
- **Work tray rows no longer pile up.** Rows that leave Running while Today or Yesterday is folded disappear at once instead of fading over the group header. Running stays expanded.
- **Antigravity edits show their diff.** `edit_file` calls with `Target` and `Replacement` arguments produce the +/- counts and diff.
- **Light/dark switch no longer stalls** while a long chat is busy: transitions are paused during the swap and the chat rows are rebuilt after the new colours paint.
- **Work panel keeps its open state** when switching chats.
