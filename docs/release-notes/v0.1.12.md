### What's new

- **Your OpenCode models:** the model picker lists every model your OpenCode install offers, read from the CLI at start-up and given readable names. Before, it was a fixed list of free models. If the CLI cannot be read, the built-in list is used.
- **OpenCode shows its work:** its reasoning shows in the chat, and each tool call shows with its command or file, followed by its result. The cost of a turn is added up and shown in the footer.

### Fixes

- **OpenCode respects AgentDeck's approval mode:** each turn now runs on its own OpenCode server. Before, the shared background service ignored AgentDeck's settings, so a shell command you had denied could still run. It also no longer interferes with your own OpenCode session.
- **Quick tool calls from OpenCode show as one step:** a tool that had already finished when it was reported used to appear as a bare result with no call.
- **Image settings popovers are better sized:** the settings menu is narrower and the model list wider, and the "No AI models" message fits.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
