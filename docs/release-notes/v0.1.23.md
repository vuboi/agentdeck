### What's new

- **Gemini image models:** the image panel lists Google's Nano Banana models (2.1, 2 Lite, 2, Pro) under their own "Google Gemini" heading, below a "Codex" heading for the GPT models. They use the key of your Gemini provider (Settings, Cloud providers) and follow the ratio, resolution and reference images you pick. Each image generator is now a separate backend, so another provider can be added without touching the run loop.
- **Page memory for the Preview agent:** elements the agent found on a site are kept on this computer, so `browser_recall` can look them up (and the steps that worked, via `browser_remember`) instead of scanning the page again.
- **An About page in Settings** with the logo, version, a short description and links to GitHub and the releases. "Check for updates" there turns a spinner, opens the update dialog when a build exists, and otherwise says AgentDeck is up to date.
- **Hidden models:** Codex and OpenCode models their CLIs keep out of the list now show under a "Hide" heading. The model menu orders Free, then Hide, then Paid.
- **Image panel providers:** the image panel offers the same providers and connectors as the chat model menu, including custom ones for prompt suggestions.

### Fixes

- **Account tools are pinned and limited:** `codex-auth` and `cswap` install at a fixed, reviewed version, and AgentDeck only runs the commands it needs (list, switch, remove, login), never the rest.
- **All switches use the dot style**, and the Fast mode switch is small, in both model menus. The Scan and Refresh buttons in Settings are outlined.
- **Model rows** show the provider name first and shorten the model name, with no tooltip on the chosen one. Models are sorted before the list draws, so it no longer reorders after opening.
- **A stray scrollbar** in nested model menus after hovering a row is fixed.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
