### What's new

- **Claude API credit:** add a Claude Console API key in Settings > Providers and the Claude picker lists every model again under "Claude credit". Claude Code then runs on that key, so the Console credit pays (a grant or a top-up), not your plan. With the Console sign-in added, the credit left shows under the message box as a bar and refreshes after each reply.
- **Saved keys stay hidden:** once saved, an API key reads as `sk-ant…••••1234` and is never shown again. Replace pastes a new one; leaving it empty keeps the saved key.
- **One file for every address:** providers, connectors, free cloud presets and local model servers (Ollama, LM Studio, llama.cpp) are declared in one place, read by both the app and its back end.
- **AgentDeck's own tools everywhere:** the built-in MCP server (browser, code index, checks, delegation) is listed for Claude, Codex, OpenCode, Antigravity and custom providers. Free-tier providers still get none of it, and cannot reach it through their web tools either.
- **Drag to reorder** the agents that carry on when one fails, with their logos.
- **Notifications with the AgentDeck logo** on Windows, without the check mark.

### Fixes

- **Streaming answers no longer jump:** the reply being written kept falling back to a guessed height and growing again, so the text moved up and down. It now keeps its measured height, and only the paragraph being written is drawn again (about five times less work per frame on a long answer).
- **Editing a message while the agent works no longer hangs:** stopping a turn now ends the whole process tree of the CLI (on Windows, macOS and Linux), so the next turn does not wait on the old one.
- **Edit and Copy show again** right after cancelling an edit, without moving the pointer away first. Switching between a message and its edit box fades smoothly.
- **Token and cost figures roll only while a reply is written;** an opened chat shows them plainly.
- **Show more / Show less** opens a little slower and smoother.
- **The "loading earlier messages" pill** sits above the header of a forked chat.
- **Keyboard shortcuts:** the list has the same scrollbar as the chat, with its arrows.
- **System notification settings:** Send a test sits under the description, apart from the switch.
- **Testing a Claude API key** no longer fails with a 404.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
