### What's new

- **Right-click on attachments.** In the chat message box and the image generator, a right-click on an attached picture or file opens a menu. Pictures: Preview, Copy image, Copy path, Show in folder, Remove. Files: Preview, Copy file contents (text files), Copy path, Show in folder, Remove.

### Fixes

- **Browser markup:** Add notes to chat puts the written notes into the message first, then takes the picture. If the picture cannot be taken, the notes still go to the message as text, with a message saying so.
- **Network tab:** a Svelte warning about a stale assignment in the request list is gone.
