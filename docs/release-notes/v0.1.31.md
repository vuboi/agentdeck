### What's new

- **Questions from an agent, in one small card:** one question with two or three options is a quick card: the options are buttons, a click answers and sends at once, and "Other…" turns into a field (with Submit) in the same place. Longer sets of questions keep the step-by-step card, now smaller. Both have a Cancel button.
- **Skip by writing:** while an agent waits for you, a message typed in the box goes out at once instead of queueing behind the question. The agent is told what that means by the kind of thing it asked: a permission request is cancelled and its command did not run; an ordinary question is answered by your message; a question the agent marked `required` is not guessed. Cancel closes the card, lets the queued messages run, and then the chat says "Task cancelled. Send a message to go on."
- **Questions stay in the list of steps:** what an agent asked is kept as an "Asked …" step you can open (the questions and their options), next to the commands it ran. The raw `agentdeck-ask` block is never shown as text, not even while it is being written.
- **Steps read as what they do:** the first line of a group is the step that runs now ("Running pnpm test", "Using officecli load_skill word"), cut to the width, and the summary when all are done. Each step has an icon by kind, in the chat and in the Audit log (terminal, file edit, search, web, skill, MCP plug…). The tool names of Copilot, OpenCode and Gemini (`powershell`, `view`, `create`, `str_replace`…) are known, and an MCP call shows its main argument instead of raw JSON.
- **Thinking as a quiet line:** reasoning is one line like "Used 2 tools" (Thinking while it streams, Thought after), open it to read it beside a thin rule, no box.
- **Audit log:** a call and its result are one box: the command on top, a divider, the result below, one Copy button, each part scrolls on its own.
- **Delegated work by model (Usage):** how many rounds each model needed per task (the first answer, then each correction), how many tasks were right the first time, needed one fix, or were reworked, with time and cost per task. A model that needs three or four rounds stands out.
- **Read aloud:** choose the Vietnamese voice (Piper vais1000, 25hours or vivos) in Settings → Replies. The button shows two rings spreading while it reads.
- **Text appears at the model's pace:** the reveal follows how fast text arrives and keeps a small buffer, so a short answer is out quickly, a long one pours out evenly and nothing stalls between chunks. Coming back to a chat that is still writing no longer types its answer out again.
- **Files in a reply:** "Open with" moved into the ⋯ menu of each file (the right-click menu on the card is gone).
- **One permission model for every agent:** the five modes of the Composer (ask, edits, plan, auto, yolo) are defined once and mapped onto Claude, Codex, Antigravity, OpenCode and Copilot. Copilot's permission cards can be answered from the chat, and a card left open when the app reloads is closed instead of staying clickable.
- **Copilot:** its premium-request quota shows in the usage bar, and its model list comes from the same endpoint the Copilot clients use.
- **Panels and logs:** the file side panel starts closed and slides like a drawer, the error log drawer has filter tabs that stay on top and a provider logo per row, and the Tasks panel shows the prompt a running reply answers.
- **z-ui 0.1.15.**

### Fixes

- **Chats with pictures or videos jumped when they opened:** each reply drew its file cards only after the disk answered, so its row grew after it had been measured. Sizes, pictures and videos are now remembered between mounts and a box of the right size stands in until they are known; cards no longer animate in when a chat is opened again.
- **Opening a chat could freeze it:** the list of apps for "Open with" was asked for every file of every reply as the chat loaded. It is asked only when the menu opens, once per file.
- **A question card said "answered" when nothing was sent:** if a reply was running, the answers were refused but the card closed anyway. It now stays open and says so.
- **Messages typed while a question waited were queued behind it** and never went out until the card was answered. They go out now (see Skip by writing).
- **Codex web search showed no query while it ran:** the query is also read from the search action when the started event has none.
- **Replies that had just been opened again retyped their text** from the start, slowly. The text that was already there shows at once.
- **Long cells in the first column of a table** ran into the next column: the column still hugs its content but wraps.
