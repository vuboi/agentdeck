### What's new

- **Live Codex usage:** the usage of every Codex account is read straight from ChatGPT, so the figures are current. If a reading fails, the account says so ("Live usage unavailable").
- **Add an account from the chat:** the account menu above the message box has a + button that adds a Claude, Codex or Antigravity account. The menu now shows even when only one account is saved.

### Fixes

- **The quota bar shows the 5-hour window:** before, it showed whichever window had the least left, so the figure under the message box could jump between windows.
- **Free resets show on every plan:** Settings shows "Available resets" for each Codex account, as ChatGPT reports them. Before, free-plan accounts were always shown as having none.
- **Empty chats are kept when you open a new one:** a new tab or the tray's New chat no longer removes earlier empty drafts.
- **Clearer account buttons in Settings:** switching an Antigravity account shows a spinner on that row, and Add account shows "Adding…" while it works.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
