### What's new

- **Speech-to-text offline transcription.** Chat composer now supports offline voice dictation powered by a local multilingual Whisper model with Vietnamese (`vi`) and multilingual recognition. Recordings are processed locally without external cloud dependencies.
- **Dynamic live waveform visualizer.** The voice input button expands into an adaptive pill displaying real-time frequency-sensitive audio bars based on microphone input, paired with a dedicated stop control.
- **Subtle circular transcribing state.** When speech transcription is in progress, a delicate rotating light-gray ring indicates background local processing while keeping the composer clean.
- **Isolated per-session voice control.** Each chat tab manages its own recording state independently; transcribed text is safely committed to the originating chat draft even if you navigate between conversations during transcription.
- **WorkBuddy native connector.** Added native connector runtime support and chat execution for WorkBuddy models.

### Improvements & Fixes

- **Composer layout preservation.** Preserved the full action row (file attachment, mention trigger, ModelPicker, and action buttons) when toggling voice recording.
- **Robust IPC and event permissions.** Configured proper Tauri ACL capabilities for voice transcription and safe fallback for background progress events.
