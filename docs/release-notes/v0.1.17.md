### What's new

- **This is a fix release.** There are no new features.

### Fixes

- **The installed app is allowed to run all of its own features:** release builds now give the main window permission for every app command, as development builds already did. Before, some features could be refused in the installed app.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
