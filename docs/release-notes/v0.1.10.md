### What's new

- **Pictures open in the file viewer:** PNG, JPEG, GIF, WebP, BMP, ICO, AVIF and SVG files show as an image, with their size in pixels at the bottom. Before, a picture opened as text, and a large one failed with "the viewer stops at 2 MB".

### Fixes

- **A changed file opens at once:** hovering a row in Changes reads its diff and text in the background, so opening it no longer waits about half a second for git and the disk.
- **Large pictures no longer fail to open:** a PNG over 2 MB shows instead of "Can't open … the viewer stops at 2 MB".

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
