### What's new

- **Image candidates:** the generator keeps a local history of every run (a float drawer from the header, grouped by day, opened with one click). Each run records its prompt, models, time, and status. A running generation can be stopped. Prompt suggestions can come from Claude as well as Codex, and the settings popover has effort, fast mode, variants, and a nested model picker.
- **Result per run:** every candidate of a run gets its own style direction, so the variants do not come out alike.

### Fixes

- **A reply that continues another reply of the same agent is one message:** the answer after a hand-back shows under the same header, with the tokens, cost and time added up. Replies from different agents stay apart.
- **Long prompts to Codex and Claude go through stdin**, so they no longer hit the Windows command-line length limit.
- **Context menus close when their list scrolls**, instead of staying where they were opened.
- **Tooltips in the sidebar** no longer stack when the pointer moves from one item to the next.
- **Scrollbars** in the sidebar tree and floating panels are slimmer.
- **Chat and image input** have even padding and a larger minimum height.
- **Expandable rows** (agent hand-offs, command output) animate open and closed.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
