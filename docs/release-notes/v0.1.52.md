### What's new

- **Pause all in the Work tray.** A **Pause all** button sits before the fold arrow. It pauses every running worker that can be paused. The pause buttons use the same square-pause icon as the queue header.
- **Stop works on every running task.** Delegated workers stop through their task. Child chats stop their turn. Provider-native work (a background command, a sub agent) ends its chat's background run and closes its running entry.
- **One list design for background work.** The Agent & background activity card uses the Work tray list, with the same rows, states, counts and buttons.
- **Window close is logged.** Pressing X logs `close requested: hiding to the tray`. Showing the window from the tray or a second launch, and focus changes, are logged too, so a hang after closing can be traced in `debug.log`.

### Fixes

- **Finished foreground commands leave the Work tray.** A command that a task event marked as background no longer stays running after its result arrives. Only background shells and sub agents keep their running state.
- **Stop on a native task closes its stale entry.** Entries left running by an earlier turn end when Stop is pressed.
- **Workflow nodes can be stopped** while they run.
