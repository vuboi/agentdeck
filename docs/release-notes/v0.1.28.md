### What's new

- **A reply cut off by the app closing says so:** when the app closes, crashes or reloads while a reply is being written, the reply shows a line after it opens again: send "continue" to pick the work up.
- **Shorter history in a new session:** with Compress context on, a chat moved to a new session (a model or account change, an edited message) carries its last 6 messages whole and only the start of the older ones, so a long chat does not fill the context window.

### Fixes

- **File cards** have a little space between the file name and its type and size line, in messages, in the message box and in the agent's file cards.
