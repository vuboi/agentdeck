### What's new

- **File paths in answers are links:** a path in an answer (Windows, macOS or Linux, even a raw one) becomes a link showing the file name. A file that exists is bold, one that does not is faded with a "not found" tooltip; a folder gets a folder icon and opens in the file manager. Right-click: open, show in folder, copy path, copy as a `file://` URL. Paths in code are left alone.
- **Reply conventions for every new conversation:** agents are told to return files as links named after the file, with no raw paths in the text, and to save web pictures locally. Editable, and switchable, in Settings > Replies.
- **Pictures and videos from a reply as small thumbnails:** pictures from the web are fetched by the app and shown; videos show their first frame with a play button, and clicking opens them in the same gallery as the pictures.
- **Read aloud:** a speaker button under each answer. Vietnamese is read by an offline voice (Piper, downloaded the first time, about 85 MB); English by the system voice.
- **Project memory:** a short note per project (`.agentdeck/memory.md`) that every agent reads when a conversation starts and adds to as it learns. Edit it in Settings > Memory.
- **One reply, one block:** replies that follow one another show the model name once, the copy button once, and the token and cost figures of the whole run; a thin line still separates them. Optional lines between replies and session notes (resumed, compacted, new).
- **Usage:** estimated cost per month, free models listed apart, no manual prices.
- **Add to chat from a file** attaches the selection as a file chip instead of pasting a code block.
- **File view toolbar** folds its buttons into a menu when the panel is narrow.

### Fixes

- **A reply cut off by a newer message** no longer shows an empty model line or "You stopped after…". Only the Stop button, or an error, says so; a reply that only ran steps shows just its step line.
- **A link being typed** (`[name](path)`) no longer shows its raw path and then shrinks to the name while the answer streams.
- **File cards** have a little space between the file name and its type and size line.
