# AgentDeck v0.1.34

## Store: skills and MCP

- Install catalog skills and MCP servers globally or into a selected project. Sync individual items or all items to global destinations, all registered projects, or one project.
- Skill **Sync / update** downloads and scans the current Git source, then replaces the entire managed skill folder, removing obsolete files. Preparation failures preserve the old version; replacement failures attempt rollback. Skills without a recorded Git source report that a replacement cannot be downloaded.
- Centralize provider skill destinations for Claude, Codex, Copilot, OpenCode and Antigravity. Provider folders use managed links to the library so replacements reach the linked destinations. Add a provider integration guide covering global/project paths and runtime discovery.
- Include Cloudflare Security Audit and external Chrome DevTools MCP in Discover. Chrome DevTools connects to a running Chrome with `--autoConnect`; installation remains opt-in and Chrome must allow the connection.
- Add domain filters for frontend/design, backend/APIs, security, DevOps/cloud, data/databases, browser/testing, media, documents/productivity and other tools. Categories are inferred from names and descriptions; Discover filters before pagination.
- Manage skill and MCP providers in a searchable popover with compact dot switches, loading on affected rows and queued saves. Preserve independent skill copies and conflicting MCP definitions.
- On Windows, retain disabled MCP definitions in Credential Manager and restore them when re-enabled. Copilot SDK receives only MCP assignments enabled for Copilot. Secure MCP disable/restore on other platforms is not included in this release.
- Keep MCP project entries separate from global entries when listing, testing and removing servers. Read Codex HTTP headers from its native configuration field.
- Standardize Store selects with ZSelect, 32px controls, equal toolbar heights and dividers. Use a 70/30 search/select split, tighter filter spacing, matching item cards and outline actions with sync icons.
- Stop querying plugin commands from providers that do not support plugin management.

## Window controls

- Drag the main window from session tabs and header icons after a small movement threshold; normal clicks retain their actions. Suppress the click following a drag and keep double-click maximize on blank header space.

## Notes

- Managed global and project skill links currently share one library version. Updating that version affects all linked destinations; independent **Own copy** folders are preserved.
- MCP sync reconciles configuration and preserves configured package versions. Chrome DevTools uses `@latest` when started. Provider enable/disable changes apply to new sessions.
- Automated checks cover configuration preservation, replacement of obsolete skill files and provider destination mappings. Full native UI, authenticated provider and external Chrome workflows still require runtime validation.
