### What's new

- **One AgentDeck at a time:** starting AgentDeck while it is already running brings up the open window instead of starting a second copy.
- **Adding an Antigravity account saves itself:** "Sign in another account" saves the current account first, opens Antigravity, waits for you to sign in, and saves the new account. You no longer press Add account by hand. If saving fails, a Retry save button appears.
- **Cancel a sign-in:** closing the account dialog while a sign-in is running stops it.

### Fixes

- **New chat always starts a new chat:** the New chat button, the sidebar, the shortcut and the tray each open a fresh chat tab with the cursor in the message box. Before, they could reopen an earlier empty draft.
- **Settings no longer loads forever:** if checking the installed CLIs or reading accounts takes too long, Settings shows the error with a Retry button.
- **Faster Refresh in Settings:** Codex and Antigravity accounts are now read alongside the CLI check instead of one after another, and finishing a sign-in no longer waits for every usage reading.
- **Antigravity accounts that need signing in again** are marked "Needs sign-in" in Settings.

### Install

Windows: `.exe` or `.msi`. macOS: `.dmg` (Apple silicon or Intel). Linux: `.AppImage`, `.deb` or `.rpm`.
