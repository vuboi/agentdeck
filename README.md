# AgentDeck

One desktop chat for all your AI coding agents: Claude Code, Codex, Antigravity, OpenCode and your own providers side by side.

Download the latest build from the [**releases page**](https://github.com/vuboi/agentdeck/releases/latest).

| System | File |
| --- | --- |
| Windows 10/11 | `AgentDeck_x64-setup.exe` or `.msi` |
| macOS (Apple silicon) | `AgentDeck_aarch64.dmg` |
| macOS (Intel) | `AgentDeck_x64.dmg` |
| Linux | `AgentDeck_amd64.AppImage`, `.deb` or `.rpm` |

Installed versions update themselves from the release feed.

This repository only publishes release builds and release notes. The source code is not published here.

Issues and feedback: [open an issue](https://github.com/vuboi/agentdeck/issues/new).
